# Personal Developer Portfolio

## Project Overview

This is my personal portfolio website built entirely from scratch. It serves as a digital resume and a centralized place to showcase my software development projects, skills, and contact information. The project focuses on clean code, semantic HTML, and pure CSS without relying on external frameworks like Bootstrap, demonstrating a strong understanding of front-end fundamentals.

## Feature List

- **Zero Frameworks:** Built with pure HTML5 and CSS3.
- **Modern Layouts:** Utilizes CSS Grid and Flexbox for a clean, structural design.
- **Custom Animations:** Includes smooth floating animations in the hero section and interactive hover effects on buttons and project cards.
- **Project Showcase:** A dedicated section displaying recent work with direct links to GitHub repositories and live demos.
- **Responsive Design:** Structured to be adaptable across different screen sizes.

## How to View or Run the Project

Since this is a static website, no complex build steps or server configurations are required.

1. Clone this repository to your local machine:
   ```bash
   git clone [https://github.com/Ahmad-Batta/portfolio_project.git](https://github.com/Ahmad-Batta/portfolio_project.git)
   ```
